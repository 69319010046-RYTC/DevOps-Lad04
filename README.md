# DevOps-Lad04 — IT Support Desk

## คำอธิบายโปรเจกต์

เว็บไซต์ตัวอย่างสำหรับระบบแจ้งซ่อมและแจ้งปัญหา IT ภายในองค์กร ผู้ใช้สามารถกรอกข้อมูลผู้แจ้ง ประเภทปัญหา สถานที่ และรายละเอียดอาการ จากนั้นบันทึกคำขอและดูหมายเลขเคสกับสถานะได้ หน้าเว็บออกแบบเป็นภาษาไทย ใช้โทนสีเข้ม และปรับรูปแบบให้เหมาะกับหน้าจอขนาดต่าง ๆ

## ความสามารถ

- แสดงข้อมูลบริการและขั้นตอนการรับแจ้งซ่อม
- รับข้อมูลคำขอผ่านแบบฟอร์ม พร้อมตรวจสอบช่องที่จำเป็น
- สร้างหมายเลขเคสและกำหนดสถานะเริ่มต้นเป็น “รอตรวจสอบ”
- แสดงรายการคำขอที่บันทึกไว้ในเบราว์เซอร์

## วิธีใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ แล้วกรอกแบบฟอร์มในส่วน “แจ้งซ่อม IT” รายการที่บันทึกจะแสดงอยู่ในหน้าเดียวกัน

## เทคโนโลยีและข้อจำกัด

โปรเจกต์นี้เป็นหน้าเว็บแบบ Static ใช้ HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งแพ็กเกจหรือเริ่มเซิร์ฟเวอร์ คำขอแจ้งซ่อมถูกเก็บด้วย `localStorage` ในเบราว์เซอร์เครื่องปัจจุบันเท่านั้น จึงยังไม่มีฐานข้อมูลส่วนกลาง ระบบบัญชีผู้ใช้ หรือการส่งคำขอไปยังทีม IT จริง
